Una pizarra, a tu ritmo.

Dibuja con lápiz, marcador o resaltador. Elige color y grosor. Suavizar corrige el temblor y las líneas casi rectas.

Mueve cualquier elemento con Seleccionar. Arrastra la esquina para redimensionar los objetos. Toca el lápiz de edición para cambiar su texto.

Explora el lienzo con Mano, la rueda del ratón o dos dedos. Pellizca para ampliar; en ordenador usa Ctrl/⌘ + rueda.

Borra partes de tus trazos con el borrador. Para quitar un objeto, selecciónalo y pulsa la papelera.

Guarda y comparte una imagen PNG o una pizarra editable. La copia automática es local; no hay edición simultánea entre dispositivos.
